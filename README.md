# Swift Practice Project

An ongoing collection of Swift exercises where I practice turning real-world requirements into clear, functional code.

Each playground focuses on a different system and helps me strengthen my understanding of Swift fundamentals, data modeling, business logic, validation, and state management.

## Current Exercises

- Bike rental system
- Meeting-room booking system
- Event RSVP and waitlist system
- Movie rental system
- Package locker tracker

## Skills I’m Practicing

- Swift structs, enums, and functions
- Arrays and dictionaries
- UUIDs and data modeling
- Guard statements and input validation
- Error handling
- Managing application state
- Writing logic for real-world rules and edge cases

## Tools

- Swift
- Xcode Playgrounds
- SwiftUI

## Purpose

This repository is a work in progress and will continue to grow as I complete new exercises and improve existing solutions. It reflects my hands-on practice with Swift and my approach to breaking down problems into manageable, testable logic.
